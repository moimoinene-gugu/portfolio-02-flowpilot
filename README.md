# 🇯🇵 日本語

## プロジェクト概要

この作品は、業務効率化を支援するSaaS（Software as a Service）を想定して制作した架空のランディングページです。

現代は情報があふれる時代です。必要な情報を整理し、その中から目的の情報へ直感的にアクセスできることは、ユーザーにとって非常に重要だと考えています。

その考えをもとに、視線の流れや情報設計、余白やレイアウトを工夫し、シンプルで分かりやすく、安心して利用できるユーザー体験を目指しました。

また、レスポンシブ対応やアニメーションなど、実際のWeb制作案件を想定した制作フローで取り組み、デザインからコーディングまで一貫して制作しています。

# 🇺🇸 English

## Project Overview

This project is a fictional SaaS landing page created to demonstrate modern front-end development, dashboard UI design, and responsive web design.

Today, we are surrounded by an overwhelming amount of information. I believe a great user experience begins by organizing that information so users can quickly and intuitively find what they need.

With that philosophy in mind, I designed this landing page with clear visual hierarchy, thoughtful spacing, and intuitive navigation to create a clean and user-friendly experience.

The project follows a real-world workflow from design to front-end implementation, including responsive layouts, animations, and interactive components.
